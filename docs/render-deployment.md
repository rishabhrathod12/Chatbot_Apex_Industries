# Deploying to Render

**Status:** files written, **never deployed**. Docker is not installed on the development machine, so the image
build and `render.yaml` are untested. Expect small first-deploy fixes. Plan names, sizes and prices in `render.yaml`
are from memory: check them in the Render dashboard.

## What the Blueprint creates (`render.yaml`)

- `apex-db`: Render PostgreSQL. The API gets its URL as `DATABASE_URL`.
- `apex-api`: the Dockerfile image running FastAPI. One instance, a 5 GB persistent disk at `/var/data` holding the
  uploaded PDFs (`UPLOAD_DIR`) and the vector index (`VECTOR_STORE_PATH`). Health check `/api/v1/health/ready`.
- `apex-web`: the same image with a start command that runs Streamlit.

## Changes made for Render

- The Dockerfile now listens on `$PORT` (default 8000 when it is not set, so local use and compose are unchanged).
- Proxy headers are trusted from `FORWARDED_ALLOW_IPS` (default `127.0.0.1`, unchanged). Render sets it to `*` so the
  login lockout and audit log see the real client address instead of the proxy's.
- The Docker `HEALTHCHECK` follows `$PORT`.

## Steps

1. Push the repository (with these files) to GitHub and create a Blueprint in Render from it.
2. When asked, enter `OPENAI_API_KEY`, `SETUP_TOKEN` (a long random value) and, for `apex-web`, `API_BASE_URL`
   (`https://<apex-api address>/api/v1`; known after the API service exists, so deploy the API first and then fill it in).
3. `JWT_SECRET_KEY` is generated by Render.
4. After the API is healthy, open the web address and create the first Super Admin on the setup page using
   `SETUP_TOKEN`, then remove `SETUP_TOKEN`.

## Known risks

- **Disk permissions (untested).** The image runs as a non-root user. If the mounted disk is not writable by it,
  `/api/v1/health/ready` reports storage `failed` (503). Check the first deploy's logs.
- **One instance only.** The embedded vector store opens from one process; overlapping instances during a deploy
  could conflict. `autoDeploy` is off so deploys are deliberate.
- **Memory.** Importing the API alone is about 164 MB (measured); 512 MB is too tight, hence `standard`.
- **Backups.** `scripts/backup.py` is for a local install. Use Render's database backups, and decide how to copy the disk.
- **No lock file.** Builds install the newest allowed versions.
- **Cost.** Every upload and question calls OpenAI with your key.
